# 📚 Keymaps - Configuración Breiner + ChatGPT

Este documento lista todos los atajos de teclado configurados en tu Neovim, organizados por funcionalidad y plugin.

---

## 🛠 Trouble.nvim
| Atajo | Acción |
|------|--------|
| `<leader>xx` | Toggle Trouble |
| `<leader>xw` | Diagnósticos del workspace |
| `<leader>xd` | Diagnósticos del documento actual |
| `<leader>xr` | Referencias LSP |
| `<leader>xt` | TODOs |

---

## 🧠 GitSigns.nvim
| Atajo | Acción |
|------|--------|
| `<leader>gu` | Revertir cambio (hunk) |
| `<leader>gU` | Revertir todos los cambios del buffer |
| `<leader>gs` | Stage hunk |
| `<leader>gS` | Stage buffer |
| `<leader>gb` | Blame línea actual |
| `<leader>gp` | Vista previa del hunk |
| `<leader>gd` | Diff contra Git |

---

## 🧩 Replace (futuro - Spectre)
| Atajo | Acción |
|------|--------|
| `<leader>rh` | Buscar/Reemplazar texto |

---

## 🗺 Minimap (codewindow)
| Atajo | Acción |
|------|--------|
| `<leader>mm` | Mostrar / ocultar minimapa |

---

## 🐞 Debugging (nvim-dap)
| Atajo | Acción |
|------|--------|
| `<F5>` | Continuar |
| `<F10>` | Step Over |
| `<F11>` | Step Into |
| `<F12>` | Step Out |
| `<leader>b` | Toggle Breakpoint |
| `<leader>B` | Breakpoint Condicional |
| `<leader>du` | Toggle DAP UI |

---

## 🖥 Terminal (toggleterm)
| Atajo | Acción |
|------|--------|
| `<leader>t` | Abrir terminal horizontal |
| `<leader>tf` | Abrir terminal flotante |

---

## 🔍 Telescope
| Atajo | Acción |
|------|--------|
| `<leader>ff` | Buscar archivos |
| `<leader>fg` | Buscar texto en archivos |

---

## ⚡ LSP Actions
| Atajo | Acción |
|------|--------|
| `<leader>gs` | Ejecutar Code Action (ej: Generate Getters/Setters) |

---

# 🚀 Otros Atajos Útiles

| Atajo | Acción |
|------|--------|
| `<A-j> / <A-k>` | Mover línea o bloque hacia abajo/arriba |
| `<leader>d` | Duplicar línea o bloque |
| `<leader>dd` | Duplicar bloque y mantener selección |
| `<leader>w` | Guardar archivo |
| `<leader>e` | Abrir/cerrar NvimTree |
| `<Space>` | Leader Key |
